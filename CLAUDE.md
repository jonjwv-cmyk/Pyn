# Pyn

**Сначала** прочитай [Регламент работы](./REGLEMENT_WORK.md) — это primary workflow.

Для всех ИИ-агентов в этом репо:

- экономь токены, команды и чтение **без** потери качества;
- один проверяемый шаг за раз;
- не читай файлы «на всякий», не сканируй весь проект/home;
- не переписывай Electron/UI без доказанной ошибки и разрешения;
- ответ коротко: сделано → результат → ещё нужно: да/нет;
- перед первой **записью** — минимальная инспекция + checkpoint;
- после правок — проверки из регламента (typecheck / dev / UI).

При конфликте с «развёрнутым» дефолтом агента по объёму чтения/ответа —
побеждает регламент. Safety (checkpoint, evidence, no destructive) не ослаблять.
